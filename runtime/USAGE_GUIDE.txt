TankEye-Iris 使用说明
=====================

一、首次使用

1. 将 `TankEye-Iris_1.1.zip` 解压到本地磁盘，例如 `D:\TankEye-Iris_1.1`。
2. 不要直接在压缩包里运行程序。
3. 双击包根目录下的 `launch_tankeye_main_only.vbs`。
4. 第一次启动时，程序会自动在当前 Windows 用户桌面创建 `TankEye-Iris` 图标。
5. 后续可以双击桌面图标启动。

二、图片检测

1. 启动程序后，点击“加载图片”。
2. 可以选择包内 `samples\images\2.jpg` 作为演示图，也可以选择自己的图片。
3. 点击“开始检测”。
4. 程序会显示 OBB、SEG、夹取射线、抓取点以及检测结果。

三、相机检测

1. 确认电脑已经安装官方 Hikrobot MVS 相机驱动。
2. 确认相机网段和电脑网卡 IP 可以通信。
3. 在工程设置中填写相机 IP、曝光参数和现场标定。
4. 点击“打开相机”，再点击“开始检测”。

四、PLC

1. 默认 PLC 配置位于 `config\tankeye.json`。
2. 现场联调前，请确认 PLC IP、端口、寄存器地址、坐标映射和限位设置。
3. 需要离线验证时，可以使用启动命令：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device AUTO -SimulatePlc
   ```

4. `SimulatePlc` 只模拟 PLC 读写，不会连接或写入现场 PLC。

五、新电脑前置条件

1. Windows 64 位。
2. CPU 推理不需要安装 Python、CMake、Qt、OpenCV 或 OpenVINO。
3. 使用 Intel GPU 加速时，目标电脑需要安装官方 Intel 显卡驱动。
4. 使用海康相机时，目标电脑需要安装官方 MVS 相机驱动；运行包内已包含程序运行所需的海康 SDK Runtime。

六、重要目录

- `models\weights`：OBB 和 SEG 模型。
- `config\tankeye.json`：PLC、相机和工程默认配置。
- `calibration_profiles`：九点标定配置。
- `calibration_output`：标定工具输出。
- `logs`：程序运行日志。

七、问题排查

1. 程序无法启动：查看 `logs` 目录中最新的 `tankeye_*.log`。
2. 找不到相机：检查 MVS 驱动、相机供电、网段和相机 IP。
3. GPU 不可用：使用 CPU 启动，或安装官方 Intel 显卡驱动。
4. PLC 不响应联机：使用 `-SimulatePlc` 参数进行离线测试。
