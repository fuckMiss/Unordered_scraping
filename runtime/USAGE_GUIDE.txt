TankEye-Iris 1.4.5 使用说明
========================

本文件必须按 UTF-8 读写，避免中文乱码。

一、首次使用
------------

1. 将 `TankEye-Iris_1.4.5.zip` 解压到本地磁盘，例如 `D:\TankEye-Iris_1.4.5`。
2. 不要直接在压缩包里运行程序。
3. 双击包根目录下的 `launch_tankeye_main_only.vbs`。
4. 第一次启动时，程序会在当前 Windows 用户桌面创建 `TankEye-Iris` 图标。
5. 后续可以双击桌面图标启动。

默认启动会优先使用显卡加速；如果当前电脑显卡环境不稳定，程序会自动改用 CPU 启动，避免闪退。
新电脑第一次启动可能会多等几十秒；后续保留缓存后通常会更快。

二、图片检测
------------

1. 启动程序后，点击“加载图片”。
2. 可以选择包内 `samples\images\2.jpg` 作为演示图，也可以选择自己的图片。
3. “加载图片”使用后台线程读取，减少界面阻塞。
4. 点击“开始检测”执行 OBB/SEG 检测。
5. 程序会显示目标、分割区域、夹取射线、抓取点以及检测结果。
6. 真实夹爪框由工程设置中的夹爪长度/宽度和九点标定换算得到，负责可抓/不可抓颜色显示、碰撞拒抓、抓取射线 C 点和中心偏移。
7. 如果夹爪长度/宽度为 0，或九点坐标转换未启用/无效，程序会保守判为不可抓。

三、PLC 与相机
--------------

- 默认运行包可用模拟 PLC 验证界面和模型加载。
- 连接真实 PLC、真实相机或真实设备动作前，必须确认现场设备安全，并由负责人明确允许。
- PLC 地址、端口和寄存器配置在 `config\tankeye.json` 中。
- 工程设置会保存到当前运行包的 `config\engineering_settings.ini`，不同版本运行包互不共用。

模拟 PLC + CPU 启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device CPU -SimulatePlc
```

四、管理员授权
--------------

首次创建管理员账号需要 `INIT` 授权码；忘记密码重置需要 `RESET` 授权码。

请把软件显示的完整机器码发给授权码生成端，然后分别生成：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate_admin_auth_code.ps1 -MachineCode "TK-客户机器码" -Purpose INIT
```

或：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate_admin_auth_code.ps1 -MachineCode "TK-客户机器码" -Purpose RESET
```

正式运行包应包含 `config\admin_auth.key`。

五、开机自启
------------

运行 `create_desktop_shortcut.ps1` 生成桌面图标时，默认同步创建当前用户开机自启入口。

当前自启合同：

```text
-StartupProfile AutoStart -StartupDelaySeconds N
```

含义：

- 自动加载模型。
- 模型加载完成后请求进入 PLC 抓取联动。
- 可在工程设置中关闭开机自启或调整延迟秒数。
- 自启入口使用当前用户 Startup 文件夹，不使用注册表、服务或计划任务。

六、OpenVINO 缓存
-----------------

第一次加载模型可能较慢，因为 OpenVINO 会编译模型并生成缓存。缓存目录为：

```text
openvino_cache
```

保留该目录后，后续启动或加载同一套模型通常会更快。

如确实需要清理缓存，可显式启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -ClearOpenVinoCache
```

正常使用不要加这个参数。

七、常见问题
------------

1. 图片中文路径加载失败：
   将图片放到纯英文路径，并把文件名改成英文或数字。

2. 管理员授权码无效：
   检查机器码是否完整，确认 `INIT` / `RESET` 用途是否正确，并确认运行包使用正确的 `config\admin_auth.key`。

3. 第一次加载模型慢：
   这是 OpenVINO 首次编译模型的正常现象。保留 `openvino_cache` 后通常会改善。

4. 不想开机自启：
   进入管理员工程设置，关闭“开机自启”。

5. 仍然出现闪退：
   使用上面的“模拟 PLC + CPU 启动”命令复测，并把 `logs\tankeye_*.log` 最新日志发给负责人。
