# Windows Deployment

This document describes the Windows-only deployment path for TankEye-Iris.

## 1. Install Dependencies

Use Anaconda Prompt or Developer Command Prompt.

Python tools:

```bat
pip install -U openvino openvino-dev
```

Native tools:

- Visual Studio 2022 with Desktop development with C++
- CMake
- Qt 5.15.2 `msvc2019_64`
- OpenCV 4.x Windows build
- Intel graphics driver

Known local paths used by the scripts:

```text
D:\Qt\5.15.2\msvc2019_64
D:\opencv\opencv-4.12.0\opencv\build
D:\Anaconda\envs\cll_yolo\Lib\site-packages\openvino
```

## 2. Convert Models

Input ONNX files:

```text
weights\best_obb.onnx
weights\best_seg.onnx
```

Run:

```bat
python .\export.py
```

Expected OpenVINO IR files:

```text
weights\best_obb.xml
weights\best_obb.bin
weights\best_seg.xml
weights\best_seg.bin
```

## 3. Configure and Build

```bat
set openvino_DIR=D:\Anaconda\envs\cll_yolo\Lib\site-packages\openvino\cmake
set OpenCV_DIR=D:\opencv\opencv-4.12.0\opencv\build

cmake -S . -B build_win_unit -G "Visual Studio 17 2022" -A x64 -DBUILD_QT_APP=ON
cmake --build build_win_unit --config Release --target tankeye-openvino_qt_app
```

Optional command-line test targets:

```bat
cmake --build build_win_unit --config Release --target tankeye-openvino_obb
cmake --build build_win_unit --config Release --target tankeye-openvino_seg
```

## 4. Run

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1
```

Device options:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device AUTO
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device GPU
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device CPU
```

`AUTO` tries OpenVINO `GPU` first and falls back to `CPU`.

## 5. Verify Intel UHD Usage

Open the latest log in:

```text
build_win_unit\Release\logs
```

Or run:

```bat
findstr /i "OpenVINO Requested Available Selected Device GPU CPU" build_win_unit\Release\logs\tankeye_*.log
```

Interpretation:

- `Available devices: CPU GPU`: OpenVINO can see both CPU and GPU devices.
- `Selected device: GPU`: OpenVINO GPU plugin is active. On an Intel UHD-only machine, this means the integrated GPU is being used.
- `Selected device: CPU`: GPU failed or CPU was explicitly requested.

## 6. Package Runtime DLLs

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy_windows.ps1
```

The script copies:

- Qt runtime files
- OpenCV DLLs
- OpenVINO Runtime DLLs
- Intel OpenVINO CPU/GPU plugin DLLs
- Qt image/platform plugins
- `qt\assets\app_logo_cutout.png`

## 7. Intel GPU Kernel Diagnostics

If `kernel.errors.txt` appears with CISA or kernel header messages, it was generated by the Intel GPU compiler used by the OpenVINO GPU plugin.

Recommended checks:

1. Run with `-Device CPU`.
2. If CPU works and GPU fails, update the Intel graphics driver.
3. Confirm `openvino_intel_gpu_plugin.dll` is available in the runtime directory or PATH.
4. Try another OpenVINO Runtime version if the driver is already current.
