# TankEye-Iris

TankEye-Iris is a Windows industrial vision application for unordered grasping. It uses YOLOv11 OBB and YOLOv11 SEG models through OpenVINO, keeps the Qt operator UI, and preserves the existing grasp pose post-processing and PLC output flow.

The runtime is OpenVINO only. CUDA, TensorRT, DirectML, Linux launchers, and `.engine` files are not part of this Windows package.

## Runtime

- OS: Windows x64
- UI: Qt 5.15.2 `msvc2019_64`
- Inference: OpenVINO Runtime
- Vision dependency: OpenCV 4.x
- Default device: `AUTO`, which tries OpenVINO `GPU` first and falls back to `CPU`

When the log says `Selected device: GPU`, OpenVINO is using its GPU plugin. On a machine with only Intel UHD Graphics, that GPU is the Intel integrated GPU.

## Model Files

Expected files:

```text
weights\best_obb.onnx
weights\best_seg.onnx
weights\best_obb.xml
weights\best_obb.bin
weights\best_seg.xml
weights\best_seg.bin
```

Convert ONNX to OpenVINO IR:

```bat
python .\export.py
```

## Build

```bat
set openvino_DIR=D:\Anaconda\envs\cll_yolo\Lib\site-packages\openvino\cmake
set OpenCV_DIR=D:\opencv\opencv-4.12.0\opencv\build

cmake -S . -B build_win_unit -G "Visual Studio 17 2022" -A x64 -DBUILD_QT_APP=ON
cmake --build build_win_unit --config Release --target tankeye-openvino_qt_app
```

## Run

Default device selection:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1
```

Force Intel GPU:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device GPU
```

Force CPU fallback:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device CPU
```

Runtime logs are written to:

```text
build_win_unit\Release\logs\tankeye_*.log
```

Check selected OpenVINO device:

```bat
findstr /i "OpenVINO Requested Available Selected Device GPU CPU" build_win_unit\Release\logs\tankeye_*.log
```

## Intel GPU Kernel Diagnostics

Intel GPU driver/compiler diagnostics may create `kernel.errors.txt` with CISA or kernel header messages. This is generated by the Intel OpenVINO GPU stack while compiling kernels for the integrated GPU. It is not a Qt, PLC, or grasp post-processing error.

If inference output is correct and the log still shows `Selected device: GPU`, the file may be a non-fatal compiler diagnostic. If GPU inference fails or is unstable, test with:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch_tankeye.ps1 -Device CPU
```

If CPU works but GPU fails, update the Intel graphics driver or validate with a different OpenVINO Runtime version.
